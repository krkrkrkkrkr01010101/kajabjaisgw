# بوت الحقوق المائية للصور

بوت تيليجرام خفيف لإضافة حقوق ملكية (Watermark) على الصور، مبني بالكامل
داخل ملف `main.py` واحد، ويستخدم SQLite للتخزين، ومناسب للتشغيل على
Railway كخدمة Worker.

## المميزات

- إرشاد المستخدم خطوة بخطوة: النص، المكان، الخط، نسبة الشفافية.
- ستة أوضاع لوضع الحقوق، منها وضع "توزيع على الصورة" الذي يصعّب إزالتها.
- دعم النصوص العربية والإنجليزية والنصوص الطويلة، مع ضبط تلقائي لحجم الخط.
- حذف الصور والملفات المؤقتة فور انتهاء المعالجة، وعدم الاحتفاظ بأي نسخة.
- فحص أولي وخفيف لرفض الصور المشبوهة (بدون خدمات خارجية).
- حماية من الفلود: حد للطلبات لكل مستخدم، حد للمعالجة المتزامنة، حظر
  مؤقت تلقائي عند تكرار الفلود.
- اشتراك إجباري قابل للتفعيل أو التعطيل من لوحة تحكم الأدمن.
- لوحة تحكم كاملة بالأزرار: إحصائيات، حظر/فك حظر، إعدادات الحماية،
  إعدادات حجم الصور، نسبة الشفافية الافتراضية، إدارة الخطوط، وضع الصيانة.

## متغيرات البيئة المطلوبة

| المتغير | الوصف |
|---|---|
| `BOT_TOKEN` | توكن البوت من BotFather |
| `OWNER_ID` | آيدي حساب المالك (الأدمن) على تيليجرام |
| `FORCE_CHANNEL_ID` | المعرف الرقمي لقناة الاشتراك الإجباري (اختياري، يمكن ضبطه لاحقًا من لوحة التحكم) |
| `FORCE_CHANNEL_USERNAME` | يوزر القناة بدون علامة @ (اختياري) |

لا تضع أي قيمة حقيقية لهذه المتغيرات داخل الكود، بل عرّفها من إعدادات
Railway (Variables) أو من خلال ملف `.env` محلي عند التجربة على جهازك.

## إضافة الخطوط

ضع ملفات الخطوط (ttf أو otf) داخل مجلد `fonts/`. راجع
`fonts/README.txt` لمزيد من التفاصيل واقتراحات لخطوط مناسبة. بدون أي
خط عربي داخل المجلد، ستظهر الحقوق العربية بجودة أقل.

## التشغيل محليًا

```bash
pip install -r requirements.txt
export BOT_TOKEN=xxxx
export OWNER_ID=123456789
export FORCE_CHANNEL_ID=-1001234567890
export FORCE_CHANNEL_USERNAME=my_channel
python main.py
```

## النشر على Railway

1. ارفع المشروع إلى مستودع GitHub.
2. أنشئ مشروعًا جديدًا على Railway واربطه بالمستودع.
3. أضف متغيرات البيئة المذكورة أعلاه من تبويب Variables.
4. تأكد أن نوع الخدمة Worker (أمر التشغيل: `python main.py`)، فالبوت
   يعمل عبر Long Polling ولا يحتاج فتح أي منفذ.
5. أضف خطوطك داخل مجلد `fonts/` قبل الرفع، أو ارفعها لاحقًا وأعد النشر.

## ملاحظة حول فحص المحتوى

الفحص المدمج لرفض الصور غير اللائقة هو فحص أولي بسيط يعتمد على تحليل
الألوان داخل الصورة نفسها، وليس بديلاً عن نظام فحص محتوى متكامل. إذا
كانت الدقة العالية مطلوبة، يفضّل ربط خدمة فحص محتوى متخصصة لاحقًا.
