ضع هنا ملفات الخطوط بصيغة ttf أو otf.

اسم الملف سيظهر كاسم الخط داخل أزرار البوت (مثال: Cairo-Bold.ttf سيظهر كـ Cairo Bold).

لضمان ظهور الحقوق العربية بشكل صحيح ومتصل الحروف، يجب أن يحتوي المجلد
على خط واحد على الأقل يدعم اللغة العربية بشكل كامل.

أمثلة لخطوط عربية وإنجليزية أنيقة ومجانية يمكن تنزيلها وإضافتها هنا:
- Cairo
- Tajawal
- Amiri
- Almarai
- Playfair Display
- Montserrat

بعد إضافة أي خط جديد، أعد نشر المشروع على Railway، أو استخدم زر
"إعادة الفحص" داخل قسم إدارة الخطوط في لوحة تحكم الأدمن.
